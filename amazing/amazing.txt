MAZE SOLVER ALGORITHMS
- BFS algorithm - Breadth-First Search.
	- Graph traveral algorithm exploring nodes level by level.
	- Starts from a source vertex and visits all adjacent nodes before moving to the next depth.
	- Uses queue data structure to tract vertices.
	- FIFO
	g(n) = distane(n), height(n) == 0.
	
- DFS algorithm - Depth-First Search.
	- Utilizes a queue to explore all neighbor cells level by level.
	- This approach guarantees the shortest path in an unweighted maze.
	- Ideal for navigation tasks where efficiency in step count is critical.
	- Uses stack data structure.
	- LIFO
	g(n) = depth(n), height(n) == 0.
	- DFS is a graph/tree traversal algorithm hat follows a path as far as it can until it reaches its goal or has nowhere else to go.
	- DFS does not care about the shortest path but rather that there even is a path.
	- In order to find the shortest path, look into Dijkstra’s algorithm.
